# Plan 1.2: Field Raid Maximum Run Time Slider & Ferry/Meadow Finish

## Objective
Add a **Max Run Time (0 = off)** slider to the Field Raid tab (`fieldraid.maxMinutes`) so that when a raid's elapsed time reaches the configured limit, the autofarm finishes forward via the River ferry (`RiverExit`) at the end of Field 10, collects the Harvest Meadow gold chest (`OpenHarvestChest`), returns to town (`HomePrompt`), and restarts if Auto Start is enabled.

## Context
Load these files for context:
- `.gsd/milestones/field-raid/MILESTONE.md`
- `luascripts/preview.lua` (`fieldraid` config, `fieldraid.backLimit`, `fieldraid.meadow`, `fieldraid.tick`, `rafting.dismissChestRewardGui`, `RaidTab`)
