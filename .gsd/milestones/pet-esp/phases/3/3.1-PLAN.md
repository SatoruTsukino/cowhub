# Plan 3.1: Companion Multiplier ESP — performance + tamed/untamed flashing

## Objective
`luascripts/companion_multiplier_esp.lua` runs its full update every Heartbeat and can call `getgc(true)` once per pet
per frame. Its label also flashes between the real bond and "Untamed". Cut the per-frame cost and make the label stable.

## Context
- luascripts/companion_multiplier_esp.lua
- rbxlx DogController: `actor.RenderRecord` = `FarmMammalInterpolation.Sample(...)` for networked pets; that sample has
  no `CompanionCare`, while `actor.Record` does.

## Root causes
1. `refreshRecords` takes `RenderRecord or Record`, so on some frames the record has no bond → falls to the 0.25 untamed default.
2. `getProfileCompanions()` runs a full `getgc(true)` scan per pet per frame whenever bond is missing; when it misses, bond falls back to untamed for that frame.
3. Folder scan, record rebuild and every label property write run every frame.
