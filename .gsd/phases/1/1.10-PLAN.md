# Plan 1.10: Mob Dodge Damage Retreat and Aerial Retreat

## Objective
Two user reports:
- Run Away doesn't escape when hearts drop.
- The aerial (into the air) retreat doesn't protect the cow.

Causes, found in luascripts/preview.lua:
1. Every heart drop triggers the aerial retreat (`aerial.checkHealth`). It runs before `dodge.process` and blocks it for 60 s, so Run Away and Teleport Away never handle damage.
2. The aerial retreat sets `root.Anchored = true`. An anchored HumanoidRootPart doesn't replicate its client-side CFrame, so the server keeps the cow where it stood and mobs keep hitting it.
3. A damage retreat with no telegraphed attacker uses `attackOrigin = rootPos`, so the away direction falls back to a fixed world +Z rotated 45°, often toward the mob. It also ends 0.6 s after the trigger (`lingerDelay`), too short to get clear.
