# Plan 1.8: Collect Grazing Bait Drops While Autofarming

## Objective
Grazing drops bait into `Workspace.GrazingBaitFind`. Add a Main-tab toggle that, while the autofarm is on, walks the cow over each drop inside the farm radius, then goes back to grazing.

## Context
- luascripts/preview.lua (staging; promote later): `farm` state (~L396), `farm.processMovement` (~L5460), the Main toggles
- luascripts/bait_drop_esp.lua: model position from PrimaryPart or first BasePart; pet meals (`AnimalTamingMeal`) are not drops
- No game dump names `GrazingBaitFind` (the dumps predate it), so support either shape:
  - a Folder whose children are the drops;
  - the drop itself (Model or BasePart).

## Tasks
