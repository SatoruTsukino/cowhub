# Plan 1.1: Pet ESP with Temperament Readout

## Objective
Standalone ESP (`luascripts/pet_esp.lua`) that highlights every pet model under
`workspace.LocalDogs` and `workspace.LocalBarnCats` and labels each with its
Disposition plus temperament vector (AnimalTemperament traits).

## Context
- luascripts/bird_nest_esp.lua (ESP lifecycle pattern: _G guard, destroy, heartbeat)
- Opiumware/workspace/AnimalTemperament_ModuleScript_82507849398215_Source.txt (Sample PRNG, salts, Disposition rules)
- Place rbxlx: DogController.new / BarnCatController.new — `{ Folder = <LocalDogs|LocalBarnCats>, Actors = { [key] = { Model, Record, RenderRecord } } }`.
  Models carry no attributes; model→record mapping exists only in controller Lua state.

## Tasks
