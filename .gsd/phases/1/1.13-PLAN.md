# Plan 1.13: Persistent Walkspeed Settings

## Objective
Make the walking speed and retreat walk speed settings persistent across game sessions and re-executions in both `luascripts/cowhub.lua` and `luascripts/preview.lua`. Currently, whenever scripts are re-executed or reconnected, Walking Speed defaults back to `Normal (1.0x)` and Retreat Walk Speed defaults back to `26 studs/s`. This plan persists both values to `cowhub/CowHub_Settings.json` in the executor workspace, loads them on startup to initialize `farm.patternSpeed` and `dodge.walkSpeed`, syncs initial UI element options, saves on any UI change, and wires full restore support into the 6-hour AFK session persistence system.

## Context
- luascripts/cowhub.lua: file saving (~L1155), afkRelog (~L1250), Walking Speed dropdown (~L6772), Retreat Walk Speed slider (~L6869)
- luascripts/preview.lua: file saving (~L1160), afkRelog (~L1260), Walking Speed dropdown (~L6796), Retreat Walk Speed slider (~L6893)
- FUNCTIONS.md, scripts/update-functions-md.py, scripts/update-hub-header.sh
