# Plan 6.1: Daily Rewards + Quests Auto-Claim

## Objective
Add a "Dailies" section to `preview.lua` (frost, staging) that auto-collects the daily gift,
eats/saves the Large Cookie, and auto-claims finished daily quests, so an AFK session
(with afkRelog) picks up every daily reward without opening the Barn Book.

## Context
Known from decompiled client (`<executor>/workspace/cowhub/dumps/`):
- `UIController.lua:1813-1828`: daily gift = `Remotes.CraftRequest:FireServer({ Action = "CollectDailyReward", CalendarDay = offer.CalendarDay, Claimed = offer.Claimed })`
- `UIController.lua:2620`: server answers via ClientEvent `"DailyRewardClaimResult"` `{ Ok, Code, Offer }`; `Code = "OfferChanged"` → retry with new offer
- `UIController.lua:650`: offer comes from snapshot field `DailyRewardOffer` (+ `MooBucksReward`)
- `CraftingController.lua:824`: cookie = `CraftRequest {Action="EatLargeCookie"}`; `DailyRewardsPage.lua:126` also `"SaveLargeCookie"` (needs `HasVisitedCaverns`)
- `UIController.lua:1471`: quests use `Remotes.GoalRequest:FireServer(arg)` (SetActiveGoal) — claim payload UNKNOWN
Unknown: snapshot remote (who sets `_requestSnapshot`), quest list/claim payload, 15-min Moo Bucks claim (may be auto server-side).
