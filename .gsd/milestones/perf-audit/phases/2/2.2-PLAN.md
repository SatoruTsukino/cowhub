# Plan 2.2: Byte calibration, Lua heap breakdown, quality sweep, join test (tests 8, 9, 7, 3)

## Objective
Make the network numbers absolute (estimate vs Roblox's own byte counters), find out what fills the
~500 MB Lua heap, measure what each graphics quality level costs and saves, and measure the cost of joining a server.

## Context
- .gsd/milestones/perf-audit/FINDINGS.md
- luascripts/perf_monitor.lua (T.totals), luascripts/perf_ab.lua (window runner)
- Stats tree: `Network > … > totalBytesReceived / totalBytesSent / totalNetStreamBytesReceived` (readable, cumulative)
- `settings().Rendering.QualityLevel` is writable from the executor (checked: Level03 set and restored)
