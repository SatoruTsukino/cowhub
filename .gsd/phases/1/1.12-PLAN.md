# Plan 1.12: Chomp Reject Reduction (Zero Throughput Cost)

## Objective
Cut rejected grass bites without losing accepted bites. Chomp logs `chomp_1794256657`, `chomp_1794291967`,
`chomp_1794298090` and `chomp_1794337525` (84k sends, 4.4% rejected) show two cases that can be fixed without
sending fewer bites:
1. A stuck actor state: 215 `InvalidActorState` rejects in a row over ~126 s. Every send in that state is wasted.
2. The fallback value-scan target (`src = "value"`, 13% of sends) rejects 12.8% of the time against 2.9% for the
   game's own prediction. Far, side-on nodes (dist >= 5.75 and dot < 0.5) reject 20.5% and account for ~32% of
   all rejects. The scan breaks value ties by distance alone, so it can pick a risky node while a safer node of
   the same value is also valid.

Out of scope: dropping risky sends outright (worst case -5% accepts; needs an A/B test) and any change to the
`pred` path (its risky bucket already rejects only 3%).
