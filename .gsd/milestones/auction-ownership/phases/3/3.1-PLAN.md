# Plan 3.1: Skin Auction Live Display

## Objective
Make the Auction tab's "Live Auction House Display" section show every skin lot live (updated every second), with values that match the game's own Skin Auction panel. Then remove the "Show Current Auction Skins" button, which this replaces.

## Context
- .gsd/milestones/auction-ownership/MILESTONE.md (AO-10 … AO-12, Phase 3 research)

  - the "Show Current Auction Skins" button;
  - `auction.checkAndAutoBidLot` leader check;
  - the 1 s ticker + lot AttributeChanged hooks;
  - `cosmetics.*` (Phase 2).
- Dump: `SkinAuctionController` L130–154
