# Plan 5.4: Short Option Labels, Settings Rows, Town Auction Teleport

## Objective
Fix the UI problems found in game after plan 5.3:
1. Option labels are cut off in the dropdowns. This was reported for Chomp Options and Manatite Options.
2. The Settings button pairs wrap onto two lines.
3. The text of the Close button is not centred.
4. The Town Auction teleport needs new fixed coordinates.
5. Remove buttons that duplicate other controls.

Edits go to `luascripts/preview.lua` only. `cowhub.lua` is regenerated with the promote script.

## Context
- No hub UI was added after 4ca5b03. The 18 later commits change farm and dodge logic only, and the hub files on
  other branches differ from HEAD only in their header hash. Nothing new needs a place in the layout.
- Gen2 `CreateButton` has no option for text alignment. Its handle does not expose the underlying instance.
- Each option's state is keyed by its label. `ui.setOption` callers at `preview.lua:1476-1543` pass labels.
