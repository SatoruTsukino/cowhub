# Plan 5.3: Compact Bid Rows and Option Dropdowns

## Objective
1. Make each Town Auction slot's Minimum-bid and Custom-bid buttons fit on one line. They already sit in a row group
   (`preview.lua:8503`), but their long labels make Gen2 wrap the row onto two lines. The skin-lot rows on the
   Auction Scanner tab have the same problem.
2. Replace the clusters of secondary option toggles with multi-select dropdowns, one per cluster. Master "Enable …"
   switches stay toggles, so starting and stopping a feature remains one click. The staging-only debug toggles also
   stay toggles, because `scripts/promote-preview.py` strips them by name.

Edits go to `luascripts/preview.lua` only. `cowhub.lua` is regenerated with the promote script.

## Context
- Gen2 dropdown: `MultipleOptions = true`. The callback receives the full selection as a table. `handle:Set(tbl)`
  fires the callback. The file already uses Gen1 keys (`Options`/`CurrentOption`/`MultipleOptions`) and they work.
- AFK resume (`preview.lua` ~1415–1486) calls `Window:Set("Toggle_…", true)` for 7 of the toggles being merged.

at their defaults once and have to be re-picked one time. Master toggles keep their flags, so they still restore.
