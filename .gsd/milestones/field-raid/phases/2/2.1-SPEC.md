# SPEC.md — Mill Quests Standalone Automator (`luascripts/mill_quests.lua`)

> **Status**: `FINALIZED` (2026-11-18)

## Vision
Build a standalone executor script (`luascripts/mill_quests.lua`) that automates all three **Weekly Mill Challenges** (`FieldRaidCatalog.Challenges`) required for the **Windmill at Dusk** (`WindmillAtDusk`) cosmetic coat, with an unobtrusive HUD/control panel and full telegraph survival.

## Target Challenges
1. **Challenge 1 (bit 1):** *"Harvest ripe wheat in Fields 3, 4 and 5 in one outing."*
2. **Challenge 2 (bit 2):** *"Take three ripe bites in Field 8 without taking damage between them."*
3. **Challenge 3 (bit 4):** *"Dodge an Ogre stomp aimed at you, then clear Ogre’s Acre."*

## Functional Requirements
- **REQ-01 Live Progress Sync:** Query `FieldRaidRequest:FireServer("Ledger")` on startup and after runs to read `Record.Challenges` bitmask (bits `1, 2, 4`) and skip already-completed challenges (with an optional manual override in UI to force any challenge).
- **REQ-02 Standalone Self-Contained Execution:** Works without `cowhub.lua` loaded. If `_G.CowHubFieldRaid` is active, automatically pauses `fieldraid.auto` on start so movement does not conflict. Re-executing cleanly tears down the previous instance via `_G.CowMillQuests.destroy()`.
- **REQ-03 Telegraph Survival & Blink Dodge:** Listen to `ClientEvent("FieldRaid", msg)` for `Windup`, `ProjectileAim`, `BarrageMark`, `CancelWarning`, `EnemyDefeated`, and `Hurt`. Evaluate danger using `ReplicatedStorage.CowGame.Shared.FieldRaidCombat.Contains` + `FieldRaidEnemies.Move`, blink-dodging to safe ground (`spotClear`) within bounds before strike resolution.
- **REQ-04 Ripe Wheat Bell Navigation:** Listen for `Kind == "Bell"` (`Position`, `Opens`, `Closes`, `Row`) and `RaidRipe == true` wheat cells in `workspace.NorthRiverRaidView`. Navigate toward the active/ripening bell position inside the target field band (`FieldRaidLayout.Band`), wait if `Opens > serverTimeNow`, and bite via `ChompRequest:FireServer(nodeId, nil, serial)` once in reach (`<= 9` studs), confirming acceptance via `ClientEvent("GrazeResult")` + `FieldRaidGraze` (`GrazeStart`).
- **REQ-05 Challenge 1 State Machine (Ripe F3 → F4 → F5):**
  - Enter solo raid (`FieldRaidRequest("Solo", 1)`).
  - Advance to Field 3; hold inside Field 3 band until a ripe wheat bite is confirmed (`GrazeResult.Accepted == true` while `RaidRipe` / `Bell` active).
  - Advance to Field 4; hold until ripe bite confirmed.
  - Advance to Field 5; hold until ripe bite confirmed.
  - Note: Does not require clearing Field 10; can continue straight into Challenge 2/3 in the same run if enabled, or bank safely if only Challenge 1 was selected.
- **REQ-06 Challenge 2 State Machine (3× Ripe Bites in Field 8, No Damage Between):**
  - Push to Field 8 (`City Guard Granary`).
  - Sweep/patrol within Field 8 band while prioritizing `Bell` / `RaidRipe` wheat and keeping distance from guards/warlocks.
  - Track `f8RipeStreak`: increment on confirmed ripe bite in Field 8; reset `f8RipeStreak = 0` immediately on `Kind == "Hurt"` with `Result.Applied == true` (or `Hearts` drop).
  - Complete once `f8RipeStreak >= 3`.
- **REQ-07 Challenge 3 State Machine (Dodge Ogre Stomp + Clear Ogre’s Acre):**
  - Push to Field 10 (`Ogre’s Acre`).
  - Locate `FieldOgre` (via `NorthRiverRaidView` `RaidMob` or `State.BossPosition`).
  - Bait `HarvestStomp`: approach within 11–14 studs of the Ogre (inside its 16-stud stomp radius) while avoiding other hazards until `Windup` with `Species == "FieldOgre"` and `Attack.Move == "HarvestStomp"` fires.
  - Immediately blink-dodge outside the 16-stud stomp circle; verify `serverTimeNow > StrikeAt + 0.25` without `Hurt` applied -> set `stompDodged = true`.
  - Once `stompDodged == true`, navigate forward (`-Z`) to the far riverbank `RiverExit` ferry prompt -> complete Harvest Meadow (`OpenHarvestChest` if present -> `HomePrompt` `"Return to town"`) to clear Ogre’s Acre.
- **REQ-08 Chest Healing & Safety:** Open nearby enabled `OpenHarvestChest` prompts (healing to full hearts while protected), closing via `CloseChest` once full.
- **REQ-09 Compact UI / Status Overlay:** Minimal draggable ScreenGui (or Rayfield-free lightweight status card) showing live Challenge 1/2/3 checkboxes, current phase/field/streak, Start/Stop toggle, Target Challenge selector (`Auto (Incomplete)` / `1` / `2` / `3`), and Bank & Leave button.
- **REQ-10 Constraints & Logging:** Persist optional run logs only under `cowhub/millquests/` if enabled; Luau compile clean with zero errors and max register < 200; index new functions in `FUNCTIONS.md` if applicable and verify with `scripts/update-functions-md.py --check`.

## Non-Goals
- Modifying `cowhub.lua` or `preview.lua` (user requested standalone `luascripts/mill_quests.lua`).
- Automating Blacksmith Anvil shifts or Gardening Hoof Mill.
