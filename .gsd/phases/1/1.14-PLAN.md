# Plan 1.14: Skip Risky Fallback Bites (A/B Toggle)

## Objective
Plan 1.12's tie-break had no measurable effect: in chomp_1794344567, 75% of fallback (non-`pred`) bites were still
far and side-on (dist >= 5.75, dot < 0.5) and rejected 22.7% of the time. Add a preview-only toggle that never sends
those bites, so an A/B run can measure fewer rejects against lost accepts (worst case ~5.6% of accepts).

## Context
- luascripts/preview.lua: `chomp` table (RISK_DIST / RISK_DOT), `farm.processGrassChomp` `tryCandidate`, `chomp.send` log,
  config save/load (Autofarm block), Autofarm "Chomp Options" dropdown

## Tasks

## Outcome (2026-11-10): rejected, toggle removed
A/B run chomp_1794355597 (toggle on, 66 min, same Fjord Clearing area) against chomp_1794344567 (off, 73 min):
- Accepted bites/s 1.452 vs 1.625 (-10.6%). 2,177 risky bites skipped; pauses over 1 s between bites 800 vs 593.
- Reject rate 5.53% vs 4.98%. Median server round trip 280 vs 235 ms raised `pred` rejects (5.3% vs 3.6%).
Risky fallback bites still pay off at a ~20% reject rate, because skipping one usually leaves nothing to bite.
