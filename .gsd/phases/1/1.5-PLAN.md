# Plan 1.5: Autofarm Chomp Calories/hr Stat

## Objective
Add real-time average calories per hour tracking to the Autofarm tab for when Auto-Chomper is enabled, displaying compact and exact rates on the chomp status card.

## Context
- .gsd/SPEC.md
- luascripts/cowhub.lua — chomp table (~L410), formatNumber (~L4120), Autofarm tab statusCard (~L5870)
- luascripts/preview.lua — chomp table (~L410), formatNumber (~L4129), Autofarm tab statusCard (~L6020)
- FUNCTIONS.md, scripts/update-functions-md.py, scripts/update-hub-header.sh

## Tasks

<task type="auto" effort="medium">
  <name>Calorie rate tracking and UI display</name>
  <files>luascripts/cowhub.lua, luascripts/preview.lua</files>
  <action>
    1. Define `formatCompact(n)` utility next to `formatNumber` (suffixes K, M, B, T).
    2. Add `chomp.calories = { sessionGained = 0, startTime = 0, activeDuration = 0, lastTimestamp = 0, lastCalories = nil, ratePerHour = 0 }`.
    3. Implement `chomp.getCalories()`, `chomp.resetCalories()`, `chomp.updateCalories()` tracking positive attribute deltas from `plr:GetAttribute("Calories")` (with `leaderstats.Calories` fallback), ignoring negative deltas (spent calories/rebirths).

    5. In `Toggle_Chomp` callback, call `chomp.resetCalories()` when enabled.
    6. In Autofarm `chomp.statusCard` 1 s task loop, update active duration and compute `ratePerHour = (sessionGained / activeDuration) * 3600`, displaying `Avg Calories/hr: <formatCompact>/hr (<formatNumber>)` when active.
    AVOID: subtracting raw start calories from current calories (breaks when user spends calories or rebirths).
    USE: cumulative positive delta accumulation.
