# Plan 1.1: Standalone `luascripts/caravan_autofarm.lua`

## Objective
Prove the caravan farm in its own script before touching the hub. One file holds: the CaravanState watcher, a debug probe that answers U1–U5, and an experimental farm (scare, then loot, then restore) built on the payloads from the dumps. The farm and the probe are separate toggles, both off by default. Run hub autofarm **off** while testing, because the two would fight over the character position.
