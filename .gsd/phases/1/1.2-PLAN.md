# Plan 1.2: Natural Mode, Mob Re-Arm, Bot-Check Pause

## Objective
Add Natural mode driving the game's own `CowGraze` action via `E`, re-engage after mob-aura attacks or any graze drop, and pause every chomp path while the game's bot check is active.

  <files>luascripts/cowhub.lua</files>
  <action>
    1. `chomp.natural = { held = false, lastTap = 0, notGrazingSince = nil, rearmAt = 0 }`.
    2. `chomp.isGrazing()`: `char:GetAttribute("CowAction") == "Graze"`.
    3. `chomp.canEngage()`: false if `GetFocusedTextBox()`, `chomp.paused`, or player attrs `CowClientReady ~= true`, `CatapultActive`, `CowMoofCutscene`, `CowCaptured`, `CowStunned`.

    6. `chomp.tickNatural(now)`: when grazing clear `notGrazingSince`; else start timer and call `engage()` once not-grazing ≥ 0.4 s or `now ≥ rearmAt`.
    7. Dispatcher: when `farm.autoChomp and chomp.mode == "Natural"` call `tickNatural` instead of `processGrassChomp`. Mode switch/autoChomp off/teardown → `release()`.
    AVOID: re-pressing E while already grazing in toggle mode (toggles it off).
    USE: 0.4 s debounce over replicated `CowAction`.
  </action>
  <verify>luau-compile luascripts/cowhub.lua > /dev/null</verify>
  <done>E held/tapped only when not grazing; released on disable and teardown.</done>
</task>
