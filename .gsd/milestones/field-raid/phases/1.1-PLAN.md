# Plan 1.1: Field Raid Autofarm, Raid Mob Aura, Raid Auto-Chomp, Anvil Shift

## Objective
Ship the field-raid milestone goals 1–5 in preview.lua, then promote them to cowhub.lua. Only one new top-level
local (`fieldraid`, with `fieldraid.smith`) keeps the main-chunk register count low.

<task type="auto">
  <name>Raid targets + mob aura + auto-chomp</name>
  <files>luascripts/preview.lua</files>
  <action>
    1. `fieldraid` table after the dailies engine is not possible, because the heartbeat loop needs it first.
       Declare `local fieldraid = {...}` before `farm.processMobAura`. Helpers: `fieldraid.runId()`,
       `fieldraid.view()` (workspace.NorthRiverRaidView), `fieldraid.targets(kind)` (PrimaryParts with
       CowBiteTargetKind), `fieldraid.isRaidMob(p)`, `fieldraid.wheatPoint(part, rootPos)` (closest box point).
    2. cache.cacheBackgroundElements: when in a raid, append live RaidMob PrimaryParts to cache.activeAuraMobs.
    3. dodge.isMobAlive: a BasePart with CowBiteTargetKind "RaidMob" is alive iff Health > 0 (attribute).
    4. farm.processMobAura: a raid mob → face it, `chomp.send(NodeId, part, now)` (serial wire), set
       farm.lastChompedMob/mobChompCooldown, `chomp.onMobAttack`.
    5. farm.processGrassChomp: in a raid (Remote mode) → `fieldraid.chompWheat(now, rootPos)`. It picks the nearest
       Available wheat (RaidRipe first) within chomp.REACH, faces it and calls chomp.send. It sends
       `FieldRaidRequest("GrazeStart", run)` once per run id.
    USE: chomp.send for every raid bite, because the server checks the serial wire and the chew cooldown.
    AVOID: guessing mob payload names, since the raid id is on the part.
  </action>
  <verify>luau-compile + registers</verify>
  <done>raid mobs show in mob aura; raid wheat chomped by Auto Chomp</done>
</task>

  <files>luascripts/preview.lua</files>
  <action>
    `fieldraid.tick(now, rootPos)` is called from the heartbeat when `fieldraid.auto` is on (the dispatcher condition includes it):
    - Not in a raid: when autoStart is on, every 20 s fire `FieldRaidRequest("Solo", 1)`. After 3 misses, set status "walk to the Field Raid board".
    - In a raid: (a) Hearts/MaxHealth ≤ bailPct, or bag Calories ≥ target, or run age ≥ maxMinutes → walk to GateExit and
      fireproximityprompt (leaving=true). (b) An owned, enabled OpenHarvestChest within 60 studs → walk there and fire it.
      (c) A raid mob within aura range → bite it, and stay put. (d) The nearest Available wheat → chompWheat. Otherwise MoveTo the
      nearest wheat. (e) No wheat seen for 8 s and level < maxLevel → MoveTo 30 studs deeper (direction Arrival → FieldSoil).
    - ClientEvent listener (`"FieldRaid"`): track Level (Reset/FieldChanged/State), Bag.Calories, Ended → clear run state.
    - Tab "Field Raid": status paragraph, toggles Auto Field Raid / Auto Start Next Raid, sliders Bail Hearts %,
      Max Field Level, Bank At Calories (0 = off), Max Run Minutes, button Start Solo Raid, button Bank & Leave Now.

<task type="auto">
  <name>Blacksmith anvil shift</name>
  <files>luascripts/preview.lua</files>
  <action>
    `fieldraid.smith` loop (token pattern like dailies.start), every 3 s while the toggle is on:
    - require Shared.DayNightCycle + SmithingRules (pcall). Skip unless SmithingRules.Open(sample) and the cow is not in a raid.

      Finished/Ready → SmithJobClaim(cycle) at the anvil. Paid → done for this cycle; teleport back to the saved CFrame.
    - Toggle "Auto Blacksmith Shift" on the Field Raid tab, plus a status line.
    AVOID: running while a raid, caravan or voyage owns the character.
  </action>
