# Plan 4.1: Leader Pet Teleport — identify pet by seed, keep highlight on it

## Objective
`luascripts/leader_pet_teleport.lua` teleports correctly, but its highlight picks the nearest model of the species
within 45 studs once, 0.2 s after the teleport. That misses pets that stream in late or roam away, can pick a family
member (homes share `FamilyId`), and goes stale when pooled models are reused. `HIGHLIGHT_DURATION` is unused.

## Context
- luascripts/leader_pet_teleport.lua
- luascripts/pet_esp.lua (getgc controller lookup: `{ Folder, Actors = { {Model, Record, RenderRecord} } }`)
- Shared AnimalHabitatCatalog: each home has a fixed `Seed`; the catalog seeds match it. Pet seed == home seed is
  assumed (spawn code is server-only), so a seed miss must be visible, not silent.
