# Plan 1.1: Passive Performance Monitor

## Objective
A standalone executor script that records network traffic and client performance without changing
anything in the game, so later analysis has real numbers behind each suggestion.

## Context
- .gsd/milestones/perf-audit/MILESTONE.md
- luascripts/voyage_telemetry.lua (log format, JSON encoder, Stop() pattern)
- luascripts/caravan_autofarm.lua L480–500 (`__namecall` hook; defer work out of the hook)

## Tasks

<task type="auto">
  <name>Write luascripts/perf_monitor.lua</name>
  <files>luascripts/perf_monitor.lua</files>
  <action>
    1. `_G.CowPerfMonitor` singleton with `Stop()`, `Mark(label)`, `Census()`; running again replaces it.
    2. Outgoing: `hookmetamethod(game, "__namecall")`, only `FireServer` / `InvokeServer` on RemoteEvent,
       UnreliableRemoteEvent, RemoteFunction. Inside the hook only pack args and `task.defer` the accounting.
    3. Incoming: `OnClientEvent` on every remote event under `ReplicatedStorage` (+ DescendantAdded).
    4. Per remote+action stats: count, est. bytes, max bytes, identical-payload repeats, ours (checkcaller).
    5. Every 1 s an `S` line: fps, worst frame ms, Stats times, kbps, ping, memory, instances, churn, net msgs.
    6. Every 10 s an `R` line per remote+action active in the window; every 60 s a render census `C` line.
    7. Writes to `cowhub/perflogs/perf_<time>_<id>.log`, flushed every 2 s; summary JSON on Stop and every 30 s.
    AVOID: namecalls (GetFullName, :IsA) inside the hook, because they overwrite getnamecallmethod.
    AVOID: one big GetDescendants walk per frame, because the monitor itself would cost FPS. Census is chunked.
  </action>
  <verify>
    luau-compile luascripts/perf_monitor.lua > /dev/null
    LC_ALL=C luau-compile --text luascripts/perf_monitor.lua | grep -o 'R[0-9]\{1,\}' | tr -d 'R' | sort -n | tail -1
  </verify>
  <done>Compiles with 0 errors, max register < 200, no FireServer/InvokeServer calls of its own.</done>
</task>
