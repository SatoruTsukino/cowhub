# Plan 1.4: Natural Mode Graze-State Fix (UAT gap)

## Objective
Natural mode keeps untoggling grazing. UAT log `chomp_1793741647.jsonl`: across 60 s in Natural mode, `graze` logged `on=false` once and never `true`, and `natural tap` fired every ~3 s. Root cause: `chomp.isGrazing()` reads `Character.CowAction == "Graze"`, which no dumped game script sets. The real state is the InputController's private `_grazing` field, so every watchdog tap under `CowGrazeToggle` flipped a live graze off.
