# Plan 2.1: Auto-Bid Unowned (Town Auction + Skin Auction)

## Objective
Add an "Auto Bid Unowned" toggle to each auction tab. When it's on, the existing auto-outbid / auto-buy fires on every lot whose cosmetic the player does not own, so no per-slot toggles are needed. Ownership comes from the game's own `CosmeticConfig.IsOwned`, the same check the Closet, Town Auction and Skin Auction UIs use.

## Context
- .gsd/milestones/auction-ownership/MILESTONE.md (AO-05 … AO-09)
- luascripts/preview.lua:
  - `townAuction.getProfile` / `getCosmeticConfig` / `formatOwnership` (Phase 1);
  - `townAuction.hasAnyAutoBidActive` + `checkAndAutoBidSlot`;
  - `auction.checkAndAutoBidLot` + its loop (`while auction.autoBidLoopRunning`) + AttributeChanged hook;
  - toggles "Auto Outbid & Auto Buy" (Town) and the Auction tab auto-bid section;
  - persistence `TownAuction = {…}` save/restore (~L1141, ~L1345).
- Dumps: `SkinAuctionController` L102–116 (`CosmeticConfig.IsOwned(skinId, profile)`)
