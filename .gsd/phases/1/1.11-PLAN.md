# Plan 1.11: Autofarm Rebirth ETA Stat

## Objective
Add an approximate hours until next rebirth stat (`Next Rebirth: ~Xh`) to the Autofarm chomp status card based on live growth progress and average calories per hour.

## Context
- luascripts/cowhub.lua — chomp table (~L410), Autofarm tab statusCard (~L6680–6715)
- luascripts/preview.lua — chomp table (~L410), Autofarm tab statusCard (~L6680–6715)
- FUNCTIONS.md, scripts/update-functions-md.py, scripts/update-hub-header.sh

## Tasks

<task type="auto" effort="medium">
  <name>Rebirth ETA calculation and UI display</name>
  <files>luascripts/cowhub.lua, luascripts/preview.lua</files>
  <action>
    1. In chomp module, read `plr:GetAttribute("CowGrowthProgress")` and `currentCal = chomp.getCalories()`.
    2. Compute remaining calories until rebirth:
       - If `progress >= 1.0`, remaining calories = 0 (Ready).
       - If `progress > 0 and progress < 1.0`, `targetCal = currentCal / progress`, `remainingCal = targetCal - currentCal`, cache `cal.lastTargetCal = targetCal`.
       - If `progress <= 0`, fallback to `math.max(0, (cal.lastTargetCal or 0) - currentCal)`.
    3. Compute ETA hours = `remainingCal / cal.ratePerHour` when `cal.ratePerHour > 0`.
    4. Format `rebirthEtaStr`:
       - If `progress >= 1.0`: `"Ready! (100%)"`.
       - If `cal.activeDuration < 3` or `cal.ratePerHour <= 0`: `"Calculating..."`.
       - If `hours < 1`: `string.format("~%.2fh (%dm)", hours, math.ceil(hours * 60))`.
       - If `hours >= 1`: `string.format("~%.1fh (%.1f%%)", hours, progress * 100)`.
    5. Append `\nNext Rebirth: %s` to `chomp.statusCard` body `b` in both `cowhub.lua` and `preview.lua`.
    AVOID: hardcoding rebirth multiplier tables when `CowGrowthProgress` is authoritative on LocalPlayer.
    USE: exact ratio from live `CowGrowthProgress` and current calories.
  </action>
  <verify>luau-compile luascripts/cowhub.lua > /dev/null && luau-compile luascripts/preview.lua > /dev/null</verify>
  <done>Zero compile errors, register count < 200, status card displays Next Rebirth ETA during autochomp.</done>
</task>
