# Plan 4.2: Leader Pet Teleport — live location from controller Records

## Objective
Find the 8 catalog pets anywhere the server reports them, not only when their model is streamed in.
Show each one's live distance and real breed in the GUI, teleport to where the pet is now, and mark it even
without a model.

## Context
- luascripts/leader_pet_teleport.lua (Plan 4.1 tracker)
- Shared DogSnapshotCodec: decoded record carries `Seed`, `Position`, `Variant`, `Puppy` (L264-L286).
- Client BarnCatController: record carries `Coat`, `Position`, `Seed` (L147496-L147502).
- DogController:_receive fills `self.Records` from every server snapshot; AnimalVisibility.Select only decides which
  records get a Model. Records older than 4 s are dropped. Server send range is unknown.
