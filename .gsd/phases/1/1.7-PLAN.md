# Plan 1.7: Zigzag Node Picker vs Edible-While-Growing Grass (post-update)

## Objective
After the Nov 6 game update, Remote autofarm loops over a handful of nodes instead of roaming. UAT log `chomp_1794039090.jsonl`, about 190 s in Remote mode:
- only 6 distinct nodes were bitten, against 236 in `chomp_1793858384.jsonl`;
- the median time before the cow re-bites the same node is 14.5 s, against 64.9 s before the update;
- accepted bites/s fell to 0.22, against 1.46;
- targeting is still fine: 45 of 54 sends accepted.

Grass is now re-edible 8–11 s after a bite while still `GrowthState == "Growing"`. The server accepts any node with `Available == true`; Config shows `EdibleGrowthProgress = 0.5`.

The Guided Zigzag picker (`farm.processMovement`) only targets `GrowthState == "mature"` when "Focus Only Mature Grass" is on, which is the default. In grazed fields almost nothing qualifies, so the picker finds no node and falls back to wandering, while the bites only land on the few nodes along that path.

## Context
- luascripts/preview.lua: `farm.processMovement` (~L5392), the current-target growth check (~L5465), the picker filter (~L5500)
- InputController `_findTarget` and GrassRenderController (Place dump of Nov 6): the server-side edible test is `Available == true`
