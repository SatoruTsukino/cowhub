# Plan 5.1: Register Scoping, Teleports Tab, Horizontal Button Rows

## Objective
Lower register pressure in the hub's main chunk. Move every teleport button into its own tab. Use Rayfield Gen2 row
groups to put related buttons side by side. Gameplay behavior does not change. Edits go to `luascripts/preview.lua`
only. `luascripts/cowhub.lua` is regenerated with `scripts/promote-preview.py`, because today cowhub.lua is exactly
promote(preview.lua).

Branch: `refactor/teleports-tab-horizontal-buttons`.

## Context
- luascripts/preview.lua (staging, the source of truth)
- luascripts/cowhub.lua (generated by scripts/promote-preview.py)
- scripts/promote-preview.py (strips debug toggles by `<Tab>:CreateToggle` + name; matching is indent-agnostic)
- Rayfield Gen2 groups: https://docs.sirius.menu/rayfield-gen2/tabs#groups. `tab:CreateGroup()` defaults to a row.
  Rows hold buttons, toggles, stats and sliders, and wrap when full. PascalCase keys (`Name`, `Callback`) are accepted.

Baseline (commit 2da6a4a):
- Peak register in both files is 160. The peak comes entirely from the main chunk, which has 162 top-level `local`
  declarations. The next-highest function is at 38.
- Elements are built with `Name =`/`Callback =` keys. The file does not use `CreateGroup` anywhere.

## Performance scope
Scoping the locals does not change runtime cost; it only affects compile-time register allocation. The hot loops
(farm Heartbeat, ESP, rafting) are already throttled, with 0.1–2s gates. The one notable recurring cost is
`workspace:FindFirstChild("LocalTeamChest", true)`, a recursive search of the whole workspace every 2s while chest
ESP is on. Removing it is a behavior change, so it is out of this plan unless approved. Other speculative perf changes
are also excluded, because there is no in-game profiler to prove them.
