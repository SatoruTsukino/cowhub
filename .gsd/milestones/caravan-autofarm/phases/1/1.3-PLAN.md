# Plan 1.3: Integrate Caravan Autofarm into preview.lua

> Depends on Plan 1.2 UAT. Port the proven standalone logic from `luascripts/caravan_autofarm.lua`; payloads are whatever 1.2 confirmed.

## Objective
Turn the watcher into a farm. OnRoad: scare the guide to its goal. Stopped: open every crate and empty every barrel before `LootEndsAt`. Then hand control back to the regular autofarm. It must respect bot-check pauses and rate limits.

## Context
- .gsd/milestones/caravan-autofarm/MILESTONE.md
- luascripts/preview.lua: CARAVAN MODULE (ported from caravan_autofarm.lua), `setRootCFrame` L192, `chomp.fire` L2000, `BLOCK_ATTRS` L425, the bot-check heartbeat gate (Plan 1.0), the reward-GUI closer L10449

<task type="auto">
  <name>Scare phase (OnRoad)</name>
  <files>luascripts/preview.lua</files>
  <action>
    `caravan.scareStep(state, now)`:
    1. Target = the guide part (U5) or `caravan.pose(state)`. Use `setRootCFrame` to put the root ≤ 3 studs from the target, facing it, and update it each step (the caravan moves).
    2. Moo every ≥ 1.55 s (client cooldown 1.5 s, rate limit 2 cap / 0.667 per s). Use `MooRequest:FireServer("GrumpyMoo")` only if owned/validated in 1.1, else `FireServer()`. Add Stomp per U2 if it's a separate budget.
    3. If `FrightMissed` arrives (U1), log it and move 1 stud closer.
    4. Stop when `Phase ~= "OnRoad"` or `fear >= goal`.
    AVOID: firing faster than the bucket refill, because rejected moos are a detection signal and give no points.
  </action>
  <verify>luau-compile + register check &lt;200</verify>
  <done>Compiles. The moo cadence is never below 1.5 s (a unit-like log line holds the interval).</done>
</task>

<task type="auto">
  <name>Loot phase (Stopped)</name>
  <files>luascripts/preview.lua</files>
  <action>
    `caravan.lootStep(state, now)`, with `caravan.targets(state)`:
    1. Crates first (unopened for the local userId): move ≤ 4 studs from the hitbox, then `KickRequest:FireServer({ Position = hitbox.Position, RequestId = n }, nil)` with the payload per U3. Respect `CowNextKickAt` / `CowKickPendingUntil` and ≤ 3/s. Skip all kicking if `CowUpgrade_HindStrength < 1`.
    2. Barrels with portions > 0: move into bite range (U4) and fire via the existing `chomp.fire(nodeId, hitbox, now)` path, so the serial and rate gate are shared with grass. Keep the per-barrel cooldown = `CaravanConfig.BiteCooldownSeconds`. Rotate between barrels while one is cooling down.
    3. Done when all crates are opened and all barrels are 0, or `now >= lootEndsAt`.
    AVOID: a second ChompRequest sender, because two senders would race on the chomp serial and the 8/s bucket.
  </action>
  <verify>luau-compile + register check &lt;200</verify>
  <done>Compiles, and every barrel bite goes through `chomp.fire`.</done>
</task>
