# Plan 3.1: Fjord river not loading on some servers

## Objective
Find which stage fails when the rafting river does not load: the server never sends it, the client receives it but
does not build it, or a client script errors. Find whether it follows the server (uptime, state) or cowhub.

## Context
- luascripts/perf_monitor.lua, luascripts/cowhub.lua (`__namecall` hook L1993 passes through; river listeners only read)
- ClientEvent river messages: RaftRiverLoad (20–130 KB), RaftRiverKeep (87 B), RaftRiverCancel; client sends
  RaftingRequest RiverReady ~1/s while rafting
- Last raft log came from a server ~22 h old (DistributedGameTime 78,786 s)
