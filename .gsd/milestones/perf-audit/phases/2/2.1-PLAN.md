# Plan 2.1: Graphics A/B, long soak, menu leak test (tests 6, 1, 2)

## Objective
Turn the rendering findings into measured costs (ms of GPU/CPU per feature), settle whether memory and
per-frame connections grow over a long session, and find UI leaks by opening and closing menus repeatedly.

## Context
- .gsd/milestones/perf-audit/MILESTONE.md, FINDINGS.md
- luascripts/perf_monitor.lua, luascripts/conn_probe.lua
